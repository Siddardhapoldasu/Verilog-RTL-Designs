
# 🔢 4-Bit ALU using Verilog HDL

This project implements a simple **4-bit Arithmetic Logic Unit (ALU)** using **Verilog HDL**.  
The ALU performs different arithmetic and logical operations based on the select input.

---

## 🚀 Features

✅ 4-bit ALU Design  
✅ Verilog HDL Implementation  
✅ Testbench for Simulation  
✅ Waveform Verification using EDA Playground  
✅ Beginner-Friendly RTL Project

---

## ⚙️ Operations Supported

| Select (`sel`) | Operation |
|----------------|-----------|
| 000 | Addition |
| 001 | Subtraction |
| 010 | AND |
| 011 | OR |
| 100 | XOR |
| 101 | NAND |
| 110 | NOR |
| 111 | NOT A |
